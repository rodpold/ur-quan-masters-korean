# 고유명사와 설정 용어집

`glossary.ko.json`을 번역 표기의 기준 파일로 사용합니다. 게임에 무차별 치환하지 않습니다.
처음 등록한 종족 음역은 검토용 제안이며 공식 한국어 번역이나 사용자 승인 표기가 아닙니다.

| 상태 | 의미 |
|---|---|
| in_use | 기존 패치에서 사용 중. 최종 승인과는 다름 |
| proposed | 검토 중인 후보. 대화 번역 시 채택 여부를 기록할 것 |
| approved | 사용자와 합의한 확정 표기 |
| preserve | 세이브의 실제 사용자 지정 이름 등을 원문 그대로 유지 |

- `id`는 변하지 않는 식별자, `source`는 원어, `ko`는 한국어 표기입니다.
- `category`와 `notes`에 종족/인물/지명/조직/개념 구분, 동음이의어와 문맥을 기록합니다.
- `ui_keys`는 현재 UI 번역과 정확히 비교할 키입니다. 연결된 표기를 바꾸면 UI도 함께 수정해야 합니다.
- 번역 전 용어집을 확인하고, 새 고유명사는 본문에 쓰기 전에 등록합니다.
- 표기 변경 시 관련 대사를 검색하여 조사·띄어쓰기·길이·이름 삽입을 함께 검토합니다.
  단순 부분 문자열 치환은 하지 않습니다. 고유명사와 보통명사를 구분합니다.
- 종족 대화 번역 파일이 추가되면 대사 ID별 용어 참조를 연결하는 검사를 확장합니다.
  현재 검사는 용어집 구조와 명시적으로 연결한 UI 항목만 검사합니다.
- `python tools/check_glossary.py`로 중복 ID/원어, 상태, 필수 값, UI 불일치를 검사합니다.

예: Sol은 HUD에서 ‘태양’, 별 주변 공간을 말하는 문장에서는 ‘태양계’가 될 수 있습니다.
Zelnick/Vindicator를 모든 대사에서 고정 한글로 바꾸지 않습니다. 실제 세이브의 이름을 사용합니다.

종족별 글꼴은 [폰트 배정표](FONTS.md)를 참조하세요. fonts.ko.json의 glossary_ids는 이 용어집의 id를 사용합니다.
