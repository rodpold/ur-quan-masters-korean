# 고유명사와 설정 용어집

`glossary.ko.json`을 번역 표기의 기준 파일로 사용합니다. 게임에 무차별 치환하지 않습니다.
처음 등록한 종족 음역은 검토용 제안이며 공식 한국어 번역이나 사용자 승인 표기가 아닙니다.

| 상태 | 의미 |
|---|---|
| in_use | 기존 패치에서 사용 중. 최종 승인과는 다름 |
| proposed | 검토 중인 후보. 대화 번역 시 채택 여부를 기록할 것 |
| approved | 사용자와 합의한 확정 표기 |
| preserve | 세이브의 실제 사용자 지정 이름 등을 원문 그대로 유지 |

- `id`는 변하지 않는 식별자, `source`는 원어, `ko`는 한국어 표기입니다.
- `category`와 `notes`에 종족/인물/지명/조직/개념 구분, 동음이의어와 문맥을 기록합니다.
- `ui_keys`는 현재 UI 번역과 정확히 비교할 키입니다. 연결된 표기를 바꾸면 UI도 함께 수정해야 합니다.
- 번역 전 용어집을 확인하고, 새 고유명사는 본문에 쓰기 전에 등록합니다.
- 표기 변경 시 관련 대사를 검색하여 조사·띄어쓰기·길이·이름 삽입을 함께 검토합니다.
  단순 부분 문자열 치환은 하지 않습니다. 고유명사와 보통명사를 구분합니다.
- `tools/check_localization.py`는 기존 표기 잠금과 원문에 등장하는 용어의 대화 번역 표기를 검사합니다.
  정확한 원어 단위 일치 검사이므로 복수형·별칭·문맥·조사의 적절성은 별도로 검토합니다.
- `python tools/check_glossary.py`로 중복 ID/원어, 상태, 필수 값, UI 불일치를 검사합니다.

예: Sol은 HUD에서 ‘태양’, 별 주변 공간을 말하는 문장에서는 ‘태양계’가 될 수 있습니다.
Zelnick/Vindicator를 모든 대사에서 고정 한글로 바꾸지 않습니다. 실제 세이브의 이름을 사용합니다.

종족별 글꼴은 [폰트 배정표](FONTS.md)를 참조하세요. fonts.ko.json의 glossary_ids는 이 용어집의 id를 사용합니다.

`case_sensitive: true`는 Root(항성)와 root(뿌리)처럼 대소문자로 문맥을 구분해야 하는 항목의 자동 검사에 사용한다. 기본 검사는 대소문자를 구분하지 않는다. 이 설정도 문맥 검토를 대체하지 않으며 대문자화된 다른 판본에서는 별도 확인이 필요하다.

`audit_source_paths`는 일반명사와 철자가 같은 고유명사의 자동 검사 범위를 원본 리소스 경로 목록으로 제한한다. Source(소스 행성)는 현재 슬라이랜드로 대화에만 적용한다. 모든 단어를 대문자로 시작하는 일라스의 Source(원인)와 구분하기 위한 것이다. 새 리소스에서 같은 고유명사가 나오면 문맥을 검토하고 목록을 확장해야 한다. 이 필드는 번역 치환 기능이 아니며 범위 밖의 표기 검토를 보장하지 않는다.

오르즈의 별표 표현은 [orz-concepts.ko.json](orz-concepts.ko.json)에서 따로 관리한다. 원문에 표시된 구절의 대응표이며 숨겨진 의미의 정답표가 아니다. 검사기는 각 음성 구간에서 표현별 출현 횟수를 대조한다. 일반 고유명사(오르즈·타알로·안드로신스 등)는 기존 공통 용어집을 따른다.

원소 분야 용어는 elements.ko.json을 병행 사용한다. 게임 원문 Praseo- dymium, Dyprosium은 키를 보존하고 한국어에는 프라세오디뮴, 디스프로슘을 사용한다. 같은 Mercury의 원소 수은/행성 수성 구분은 ui-overrides.ko.json의 원문 해시·순서 ID별 용어로 관리한다. 행성명 잠금 mercury=수성은 유지한다. 이러한 항목은 전역 UI 문자열 치환과 동시에 지정할 수 없다.

화합물·특수 자원 용어는 materials.ko.json에서 관리한다. 아구티 결절·카론 먼지·라이스버그 나선·츠오 결정·뉴트로늄은 공통 용어집에도 연결했다. 츠오는 기존 표기를 유지한다. 일반 물질명을 대화에서 무차별 치환하지 않는다.

행성 분류명은 world-types.ko.json의 원문 해시·순서별 표기로 관리한다. 일반명사와 색상은 대화에 무차별 적용하지 않는다. 무지개 행성·산산이 부서진 행성은 기존 용어를 유지한다. 리덕스·텔루릭·비닐로그 등은 의미를 과도하게 확정하지 않는 음역 초안이다.

함선 리소스 표기는 `ships.ko.json`에서 순서 ID와 glossary_id로 연결한다. 첫 5개 레코드의 정식명·표시명·약칭은 같은 기존 한국어 용어를 재사용하며 조크-포트 표기와 아릴룰랄릴레이/촘르 혼종의 정식명은 구분한다. 함장명 403개는 아직 번역 대기다.
