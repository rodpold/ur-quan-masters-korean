# 한국어 패치 1.0.0

Steam판 Free Stars: The Ur-Quan Masters 0.8.0의 첫 한국어 번역 배포판입니다.
전체 대화의 1차 번역과 종족별 24종 한글 글꼴·페르소나, UI·선택지·대화 로그를 적용했습니다.
이후 번역·표시 수정은 실제 플레이 피드백을 바탕으로 진행합니다.

## 설치

1. 아래 Assets에서 **uqm-korean-1.0.0-windows-x64.zip**을 받습니다. Python 설치는 필요 없습니다.
2. 게임을 저장하고 종료한 뒤 ZIP을 게임과 다른 폴더에 **전체 압축 해제**합니다.
3. **UQM-Korean-Patcher.exe**를 실행하고 게임 폴더를 확인한 뒤 **1 설치 / 업데이트**를 선택합니다.
4. 완료 후 **2 한국어로 게임 실행**을 선택합니다.

Steam 플레이 버튼을 사용하려면 게임 속성의 실행 옵션에 다음을 추가하세요.

```text
--addon uqm-korean-ui-poc --menu pc --font 3do --scale none
```

기존 개발판도 같은 방법으로 업데이트합니다. 제거는 패치 프로그램의 **4 패치 제거**를 실행하고 Steam에 추가한 실행 옵션도 삭제합니다.
게임 실행 파일·원본 데이터·저장 파일은 수정하지 않습니다. 게임 데이터는 배포판에 포함되어 있지 않습니다.

[설치·업데이트·제거 및 문제 해결 안내](https://github.com/rodpold/ur-quan-masters-korean/blob/v1.0.0/README.md)

## 참고

- Windows 10/11 x64, 검증된 Steam 0.8.0 원본 데이터 대상입니다.
- 첫 화면 New Game 등의 메뉴는 원작 영문 디자인을 유지합니다.
- 전체 플레이 검수는 진행 중입니다. 모든 종족·분기·엔딩·음성 타이밍을 검증한 버전은 아닙니다.
- 기본 대전 팀 이름 10개와 일부 장식 문구는 영어로 남습니다.
- 폰트·런타임 라이선스와 출처를 배포 ZIP에 포함했습니다.
- `source.zip` 및 GitHub의 Source code 파일은 개발자용이며 일반 설치에는 Windows ZIP을 사용하세요.
- 각 배포 ZIP의 SHA-256은 `SHA256SUMS.txt`에 있습니다.
