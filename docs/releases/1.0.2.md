# 한국어 패치 1.0.2

설치 후 Steam 플레이 버튼 연결을 지원합니다. 긴 실행 옵션을 직접 입력하지 않아도 됩니다.

> **다운로드 전 확인 — Steam 재시작이 필요합니다.** 이 패치는 Steam 실행 옵션을 자동 등록하므로 처음 연결할 때 Steam 메뉴의 종료(끝내기)로 완전히 종료했다가 다시 켜야 합니다. 연결 후에는 플레이만 누르면 되며, 매번 Steam을 재시작할 필요는 없습니다.

1. `uqm-korean-1.0.2-windows-x64.zip`을 별도 폴더에 전체 압축 해제합니다.
2. `UQM-Korean-Patcher.exe`의 **1 설치 / 업데이트**를 선택합니다.
3. 연결 안내가 나오면 게임과 Steam을 완전히 종료하고 Enter를 누릅니다.
4. Steam을 다시 열고 **플레이**를 누릅니다.

연결을 건너뛰었다면 6번 메뉴로 나중에 등록할 수 있습니다. 기존 실행 옵션은 보관되며 7번 메뉴나 패치 제거 시 복원합니다. 옵션을 직접 수정했다면 자동 복원을 중단합니다.
최근 사용한 Steam 계정 하나만 연결하며, 해당 게임을 Steam에서 한 번 실행한 이력이 필요합니다.

1.0.0 사용자는 새 프로그램의 6번 메뉴만 사용해 기존 패치를 연결할 수도 있습니다.
게임 실행 파일·원본 데이터·저장 파일은 변경하지 않습니다. 번역 내용은 1.0.0과 같습니다.
1차 번역의 전체 플레이 검수는 계속 진행 중입니다.
