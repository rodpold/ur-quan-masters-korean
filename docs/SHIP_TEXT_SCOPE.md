# 함선 문자열 적용 범위

`translations/ships.ko.json`은 설치 원본 해시, 리소스 키, 순서 ID, 용어집 ID를 연결한다. 25개 파일의 첫 5개 레코드 125개를 번역하고 함장 이름 403개 중 371개에는 한국어 초안을 넣고 32개 코드형 이름은 원형을 보존한다. 원문 헤더와 모든 레코드 순서는 변경하지 않는다.

공개 shipstat.c는 일반 함선 제목에 race_strings의 인덱스 1을 StarConFont로, 함장 이름에는 captains_name_index를 TinyFont로 표시한다. save.c/load.c는 이 함장 인덱스를 8비트 값으로 저장·복원한다. 주인공 함선 이름은 GLOBAL_SIS(ShipName)를 따로 사용한다. 따라서 리소스 교체만 수행하며 사용자 이름/저장 파일을 수정하지 않는다. 이는 소스 근거이며 설치 실행 파일과 세이브의 실기 호환성 증명은 아니다.

인덱스 1의 종족 표시명은 프로젝트의 보수적 54픽셀 예산으로 검사한다. 다른 인덱스의 이름은 원래 한국어 용어를 유지하고 폭을 보고하되 모든 소비 화면에 맞는다고 주장하지 않는다. 함종명 약칭도 현재는 정식 한국어 함종명을 재사용한다. 선박 일러스트·이미지 속 글자는 이 텍스트 변경으로 번역되지 않는다.

함장명은 captain-names.ko.json에 별도로 등록했다. 안드로신스의 영숫자 식별자 16개와 슬라이랜드로의 중복 2418-B 16개는 코드형 명칭을 보존한다. 우르콴 Lord와 코르아 Death는 각각 군주/죽음으로 옮기고 숫자는 그대로 둔다. 오르즈는 별표와 기존 개념 표현을 유지한다. 수폭스의 식물 관련 이름은 뜻을 살리고, 다른 종족의 고유 이름은 음역 초안으로 관리한다. 멜노름의 색상형 이름은 개인 이름의 음역이며 행성 색상 용어로 일괄 치환하지 않는다.

기존 인물 이름 6개는 공통 용어집과 연결했다. 나머지 음역은 발음을 확정하는 공식 표기가 아니다. 예하트 Reep-eep/Leep-eep은 한국어 음역이 같아도 순서 ID는 다르며 합치지 않는다. 함장명은 원본 units.h의 STATUS_WIDTH=64보다 여유를 둔 60픽셀 너비와 흑백 PNG를 검사한다. 본편·전투 화면 실기, 발음/의미와 참조 관계의 검토는 계속 필요하다.


2026-09-26 원문 대조 갱신: 528개 전체의 번역/보존 결정을 에이전트가 검수했다. 함장명 403개는 371개 번역 초안과 32개 코드 보존으로 구성된다. ships-language-review.json은 현재 원고·함장 전용 용어집·공통 용어집·오르즈 개념표 해시에 연결된다. 음역이 공식 발음임을 주장하지 않으며 사용자 승인과 실기/세이브 검증은 남아 있다.
