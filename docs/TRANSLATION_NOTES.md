# 번역 검토 메모

## 우주기지 GET_MINERALS

색상 순서를 암시하는 영문 두문자 문장은 영어 단어 전체와 한국어 의미를 함께 남겼다. 원문에 없는 색상 정답 목록을 임의로 추가하지 않았다. 음성 구간 수는 유지했다. 이 구간은 다른 대사보다 길므로 실제 화면에서 자막 분량과 가독성을 우선 확인해야 한다. 한국어만으로도 동등한 단서가 되는 암기법은 추가 검토 대상이다.

## 우주기지 역사

헤이스가 알고 있는 범위의 정보와 추측을 유지한다. 이후 플레이어가 알아낼 진실을 미리 보충하지 않는다. 등장 연도·거리·좌표와 이름은 원문과 대조한다. 대량 파괴와 노예제에 대한 발언의 강도를 줄이지 않는다.

## 스파시 첫 교신

겁을 먹고 실제 좌표를 먼저 밝힌 뒤, 다른 분기에서는 거짓 좌표를 주는 원문의 모순을 유지한다. 프위포의 긴 자기합리화와 변명은 해요체로, 플레이어의 협박·친선 선택은 서로 구분한다.

`tools/check_spathi_layout.py`는 실제 패키지 PNG 크기와 224px 폭으로 음성 구간별 단어 줄바꿈을 추정한다. [spathic.c](https://github.com/intgr/uqm-wasm/blob/main/sc2/src/uqm/comm/spathi/spathic.c)의 폭/기준점, comm.h의 SLIDER_Y=107, units.h의 기본 320px 화면 산식에 근거한다. 이는 검토 우선순위를 정하기 위한 추정이며 엔진 렌더링과 같음을 증명하지 않는다. 음성 미사용 페이지 분할, 얼굴 가림, 실제 자막 타이밍과 선택지는 여전히 확인해야 한다.

## 스파시와 지도부 첫 교신

Evil Ones(사악한 자들)는 Ultimate Evil(궁극의 악)과 별개 명칭이다. 이름을 잘못 기억한 Fop-Dope-Bic은 포프-도프-빅으로 남긴다. 동적 이름은 원본의 함장 이름→함선 이름 삽입 순서를 유지한다. spahome.c의 자막 폭과 기준점은 일반 스파시와 같아서 `check_spathi_layout.py --species safeones`로 동일한 정적 추정을 수행한다. 실기 검증을 대체하지 않는다.

지도부의 동맹 협상은 임무 회피, 성급한 축제, 약속 불이행과 협박 뒤의 굴복을 구분한다. 사악한 자들의 피해에 대한 잔혹한 농담을 완화하지 않는다. 후속 보고에서 숨기는 계획과 끊긴 말은 설명을 덧붙이지 않고 유지한다. Jud the Vug는 기존 긴 호칭의 짧은 형태로 용어집에 연결했다.

## 아릴루

온화한 보호자 말투와 정보 은폐·위협을 함께 유지한다. 인간의 자율성에 대한 불편한 태도를 순수한 선의로 고치지 않는다. 별표가 붙은 시간과 낯선 생물 이름, 사흘이라는 설명과 17~20일 안내의 원문 표현을 그대로 보존한다. 긴 종족명은 기존 아릴룰랄릴레이 표기를 사용한다. 용어 검사는 정식 명칭 안에 포함된 약칭을 중복 요구하지 않되, 별도로 나온 약칭은 계속 검사한다.

차원문 장치의 연료 비용·행성·좌표 및 정신 지배 관련 정보는 원문 지식 범위에 맞춘다. 음성판 차이는 VOICE_EDITIONS.md 참조. 자막·선택지 실기 검토는 대기 중이다.

## 우르콴

기존 지구 경고 방송은 유지하고 나머지 75개 레코드를 추가했다. 정신 지배에 대한 공포, 노예화를 정당화하는 논리와 패전 후 생존을 바라는 경고를 원문에 맞춰 구분한다. 크저자·코르아는 인물 이름이자 집단 이름으로 쓰인다. 아릴루와 스파시가 전한 핵심 질문은 key_phrase와 동일한 문장을 사용한다. 아웃테이크는 통역 생물의 발화로 처리한다. 장문의 역사 설명 및 패전 경고 자막은 실기 배치·타이밍 검토 대상이다.

## 코르아

WE_KILL_ALL_1, KILL_BECAUSE_2, THEN_DIE와 OUT_TAKES는 코르아의 교리를 Path of Now and Forever로 부른다. 크저자 설명과 달라도 현재와 영원의 길이라는 원문 명칭을 유지하며 영원한 교리로 교정하지 않는다. 역사 질문은 식별자 이름보다 실제 본문을 따른다(예: relationship_with_urquan은 타알로 질문). WE_WERE_SLAVES와 OUT_TAKES 끝의 공백 구간도 보존했다. 원문 반복 레코드를 합치지 않는다.

검은 우르콴의 크고 굵은 폰트와 긴 역사 자막은 실제 화면에서 영역·타이밍을 확인해야 한다. OUT_TAKES의 절명/절면/절묘은 의도적인 발음 실수이며 일반 번역의 절멸 표기와 구분한다.

## 촘르

합일 과정과 함선 자료 조사는 서로 다른 process이므로 문맥에 맞게 번역한다. 자기소개 i_am_captain0/1/2는 실제 함장 이름→함선 이름 순서와 끝 공백을 보존한다. 합일 기간 35년, 폭발 범위 500킬로미터, 개조 기간 2주, 델타 크라테리스 안내를 유지한다. 이미 알고 있는 정보와 미확인 상태의 안내를 구분한다. 긴 사마트라 설명과 동적 이름 삽입 뒤 선택지 배치는 실기 검토 대상이다.

## 일라스

일반 교신과 신 사칭 통신을 구분하며 원문의 잔혹 묘사를 추가하거나 완화하지 않는다. 명령 채널 44, 좌표 022.9, 366.6, 승무원 42/44와 29년 전 설명을 유지한다. 프쿤크 사냥에서 스래대시 공격으로 넘어가는 분기의 지시와 상태 보고를 보존한다.

단어 변경 장난은 translations/wordplay.ko.json의 선택지·응답 쌍으로 관리한다. worship/warship은 현재 숭배/전함으로 의미를 유지하지만 소리의 유사성은 없어 현지화 개선이 남아 있다. 두리·그대부·딜쥐와 신 이름의 오칭을 정상 표현으로 교정하지 않는다. Excruciators는 일라스의 고문 집행자들이며 우르콴의 장치 Excruciator와 구분한다. 긴 기도문과 선택지는 실기 배치·타이밍 검토 대상이다.

## 수폭스

Root는 루트 항성, root는 뿌리다. 해당 고유명사만 대소문자를 구분해 검사한다. 모성의 Earth/Vlik 설명은 지구/흙의 중의성을 유지하며 블리크 표기를 별도 등록했다. 안타레스와 호롤로기이는 서로 다른 원문 구간에 등장하므로 임의로 통일하지 않는다. 울트론 수리 단계별 응답을 구분한다.

[supoxc.c](https://github.com/intgr/uqm-wasm/blob/main/sc2/src/uqm/comm/supox/supoxc.c)의 자기소개/함선명/동맹명 조합과 [commglue.c](https://github.com/intgr/uqm-wasm/blob/main/sc2/src/uqm/commglue.c)의 GetAllianceName을 확인했다. name_40은 공백, name_41은 ' 제국 '으로 두어 실제 함장명 뒤에 제국을 붙인다. 고정 동맹명 세 가지와 사용자 이름으로 만든 제국명을 모두 검토해야 한다. 원본 실행 파일·세이브의 이름은 바꾸지 않는다. 이 공개 포트의 코드는 구조 참고이며 실제 화면 검증을 대체하지 않는다.

## 쇼픽스티

[shofixt.c](https://github.com/intgr/uqm-wasm/blob/main/sc2/src/uqm/comm/shofixt/shofixt.c)의 construct_response를 확인했다. 자기소개는 함장명→동맹명→함선명 순서이고, look/why_here/report/bye는 상태에 따른 타나카 또는 카타나 이름을 넣는다. 고정 bye 레코드의 Tanaka는 원문 그대로 타나카로 유지한다. 제국명은 수폭스와 같은 앞 공백+실제 함장명+제국 구조를 쓴다. 공개 포트의 코드는 구조 참고이며 실기 검증을 대체하지 않는다.

일반 대사의 Dgrunti와 아웃테이크의 Ogrunti는 원문 표기 차이를 보존한다. 쇼픽스티 처녀들의 동의를 언급하는 구간을 생략하지 않는다. 마이콘 실험 장치와 제타 섹스탄티스 행성의 위치 단서, 영광 장치의 스위치 고장은 화자가 아는 정보대로 유지한다. 긴 자기소개 선택지와 전사 함성 자막은 실기 검토 대상이다.

## VUX

젝스는 워프 무효화장의 존재를 주장하다가 YUP_LIED에서 거짓말을 인정한다. 앞선 주장에 해설을 붙이지 않는다. FOOL_AIEE0의 선구자 장치 가동 명령도 원문 그대로 유지한다. 쇼픽스티 처녀들 교환 조건과 함장을 강제로 수집하려는 의도, 괴물 탈출의 갑작스러운 전환을 보존한다.

린치-나스-플로의 노란 빛과 거대한 짐승을 삼킨 길고 가느다란 생물이라는 수수께끼는 실제 별자리 답을 덧붙이지 않고 옮겼다. 델타 린키스와 알파 체렌코프는 해당 대사에만 표시한다. 반복 사과는 횟수별 거절과 최종 고백을 모두 유지한다. 외계 속담과 eye/eyes 말장난은 wordplay.ko.json의 검토 대상으로 남겼다. 긴 환대·협박 자막 및 사과 선택지의 실기 배치·타이밍 검토는 대기 중이다.

## 예하트와 반란군

[yehatc.c](https://github.com/intgr/uqm-wasm/blob/main/sc2/src/uqm/comm/yehat/yehatc.c)의 construct_response를 확인했다. 모성의 동맹 요구는 함장명→동맹명→함선명, 우주의 동맹 요구는 함장명→함선명→동맹명 순서다. name_40/name_41은 앞 공백과 실제 함장명 뒤 제국을 붙이는 기존 방식을 따른다. 공개 포트의 구조 참고이며 실기 검증을 대신하지 않는다.

예하트의 AWK!/awk!는 새 울음으로 끄악!으로 옮긴다. 일라스에서 나온 인물 Awk(오크)와 혼동하지 않도록 해당 용어를 대소문자로 구분한다. Primat는 지도자 직함으로 기존 프리마트 표기를 유지하며, 우르콴 대사의 코르아 지도자와 ABOUT_VUX의 지도부를 동일 인물로 보지 않는다. ABOUT_VUX의 General ZEX는 젝스 장군으로 유지하며 다른 대사의 제독과 임의로 통일하지 않는다.

좌표 639.5 : 231.2, 2천 년의 불패 전통, 함선 네 척 지원과 함대 빈자리만큼 지원하는 분기를 보존했다. 반란군의 ABOUT_URQUAN은 쇼픽스티 장치의 사용법을 추정하므로 단정으로 바꾸지 않는다. 프쿤크 흡수에 대한 초기 태도와 최종 기병대의 환영은 별개 상태다. 긴 역사·혁명 연설과 동적 선택지의 실제 줄바꿈·음성 타이밍은 검토 대기다.

## 행성 탐사 보고

reports.ko.json은 원본 base/lander 경로→레코드 ID→번역 본문 구조다. 원본 uqm.rmp의 STRTAB 연결을 확인해 별도 ko 경로로 덮어쓰며 실행 파일은 수정하지 않는다. 모든 원문 레코드 헤더와 빈 문단을 보존하고, 미번역 본문은 원문 그대로 포함한다. 긴 본문은 엔진의 줄바꿈·페이지 표시를 실기에서 확인해야 한다.

안드로신스 폐허의 5년/7년/10년은 서로 다른 조사 단계에서 나온 정보이므로 통일하지 않는다. 부코프스키가 자신을 다치게 했다는 것은 호손의 추정이며, 상처가 늘어나는 이유를 해설하지 않는다. 차원 피로는 아릴루의 광선 설명과 용어를 맞췄다. 모기 옴은 원문 Mosquito Mange의 기이한 검색 주제로 유지한다. 명왕성의 전사자는 다섯 명과 리버만 세쌍둥이이며 총 여덟 명을 생략하지 않는다.

최초 탐사 보고 패키지 검사는 font.lander 연결을 빠뜨렸으므로 그 통과 결과를 표시 가능성의 증거로 사용하지 않는다. 이후 전용 Galmuri9 연결, 가로 두 칸, 교대 행과 페이지 여백을 구현했다. 현재 29개 보고를 시험 설치했으며 134페이지의 정적 글리프 검사는 통과했다. 원문과 번역 JSON의 문단은 보존하지만, 게임에 넣는 본문에는 표시용 공백과 줄바꿈을 추가한다. 대화의 음성 구간 규칙과 혼동하지 않는다. 실제 페이지 전환·PC 색상 효과·입력은 미검증이다. [배치 문서](REPORT_LAYOUT.md).

설명하는 조크는 함장에게 해요체, 동료에게 따질 때는 해체다. 피크는 대체로 해체이며 모든 짧은 대사를 고함으로 만들지 않는다. 포트가 누구인지 서로 우기는 농담을 소스 화자 이름으로 해결하지 않는다. 실제 대사에도 화자 이름표를 덧붙이지 않았다. 녹색 왜성의 외계 좌표 발음은 한글로 옮기되 인간 좌표 400.0 : 543.7을 그대로 유지했다. 십억 척 허세, 제브랭키의 식성과 멸종, 다행/불행을 번갈아 말하는 식민지 피해 설명을 보존했다.
