# 이미지·미디어 번역 추적

`tools/inventory_media.py --game "게임 경로" --write-report`는 설치 패키지와 UI PNG의 원본 해시·크기·ANI 프레임·RMP 연결을 기록한다. `media-inventory.json`은 리소스 연결 근거이며 런타임 접근 가능성을 증명하지 않는다. 애드온에 같은 경로의 사본이 있어도 번역된 이미지라는 뜻이 아니다.

기본 UI PNG 420개 모두에 대해 초기 접촉 시트 육안 검토를 마쳤다. `ui-image-review.json`에 이미지별 상태를 기록한다. 이는 번역 완료/실기 통과가 아니며 초기 확인한 121개 중 34개는 한글 패널, 38개는 한글 제목을 생성했으며, 16개는 장비/거래 라벨, 5개는 함대 대전 안내, 3개는 특수 장치 안내, 21개는 조선소 라벨, 2개는 미참조 변형 번역 준비, 1개는 부분 적용, 1개는 번역 적용 대기다. 일부 작은 버튼 안내는 별도 확대 검토가 필요하다. 게임 그림은 Git에 넣지 않는다.

확인한 잔여 대상:

- activity: GAME PAUSED, TO QUIT PRESS B.
- flagshipstatus: CAPTAIN, FUEL, CREW. 사용자 요청에 따라 크기 때문에 영문으로 돌아간 HUD도 전체 번역 검토 대상으로 남긴다.
- meleemenu: SUPER-MELEE, HUMAN CONTROL, 세 CYBORG 등급, LOAD/SAVE/QUIT, BATTLE, PICK SHIP/SHIP INFO와 작은 조작 안내.
- modulesmenu: 착륙선·추진기·선실·연료 탱크·무장 등의 그림 내 이름 14개와 BUY/SELL.
- netplay: NETWORK CONTROL과 NET 상태 라벨.
- playmenu: SCAN 등 그림 메뉴 0–37, 장치 그림의 AMPLIFIED PRECURSOR BOMB/ESCAPE POD, NO LIMIT, QUIT. 38–57의 숫자는 보존한다. 60–63 일반 버전은 기존 교체 대상이나 SAFEX=16 변형은 기본 패키지 ANI/TXT/RMP 참조가 없어 번역 자산만 준비했다.
- shipyard: 3–23의 종족/함종 이름과 일부 약칭. 지난 함선 텍스트 번역만으로 이 그림은 바뀌지 않는다.

설치된 기본/음성/3DO 음악 패키지와 게임 폴더에서는 `.mle`가 발견되지 않았다. 사용자 설정 폴더의 팀은 조사하지 않았으므로 “기본 팀 파일이 어디에도 없다”는 결론은 아니다. 기본 팀 구성의 생성 코드를 계속 조사한다.

현재 세 패키지 안에는 DUK/AVI/MP4 등 조사한 영상 확장자가 없다. 그러나 기본 패키지의 LPF 2개, PNG 기반 소개/승리/엔딩 애니메이션, 통신 배경과 함선 그림은 이 결론에서 제외되며 글자 검토가 남아 있다. 별도 영상 팩은 미설치 상태이며 범위가 추가되면 재조사한다.

다음 구현은 텍스트 배치만 치환하고 그림 크기·ANI 프레임 순서·핫스폿·숫자/버튼 식별자를 보존해야 한다. 작은 영문 영역에 한글이 들어가는지는 실제 글리프와 배경 경계를 검토해야 하며, 가독성을 확인하지 않고 잘라 넣지 않는다. 이름은 기존 용어집을 재사용한다.

추가 확인: outfitmodules-055의 NO ROOM FOR LANDERS / ESCAPE POD도 번역 대상이다. 소개/엔딩/크레딧 배경 19개와 승리 애니메이션 239개·함선 소개 그림 3개를 별도로 보고 cutscene-image-review.json에 기록했다. ending-006의 THE END는 크레딧 문자열과 다른 이미지이며 끝으로 번역했다. 저작권 표시는 원본 그대로 보존하고 실기 검토는 대기다. victory2 239개와 spins 3개 그림은 접촉 시트/확대 검토에서 번역 문구를 발견하지 못해 원본을 유지한다. victory2에는 계기 숫자와 부분 갱신 그림이 있으므로 개별 PNG 확인을 합성 재생 검증으로 간주하지 않는다.

조선소는 DrawRaceStrings가 지우는 상단 영역이 11픽셀이다. 7픽셀 한글 두 줄을 단순히 키우면 영역 밖 잔상/함선 그림 겹침이 생길 수 있으므로 shipyard-label-layout-review.json에서 제약을 추적한다. 후속 구현은 레이더 내부 4픽셀까지 제목을 확장하고 모든 함선 아이콘의 상단 경계(최소 y=10)와 겹치지 않음을 검사한다. 실제 선택/배경 갱신 검증은 대기다.

일시정지/종료 안내 2개, 함대 대전 조작 방식 16개, 네트워크 조작/NET 패널 6개를 동일 크기의 새 텍스트 패널로 생성한다. 원래 입력 처리와 B 식별자는 유지한다. 초급/중급/고급은 WEAK/GOOD/AWESOME 세 사이보그 난이도에 대응한다. 기본/선택 배경·글자 색상은 각 원본 패널의 팔레트를 유지하며 음영 글자 대신 native Galmuri7을 쓴다. control-panel-checks.json의 구조 검증과 정적 미리보기는 실기 검토를 대체하지 않는다.

함대 대전의 LOAD/SAVE/QUIT 기본·선택 상태 10개를 추가했다. source_size와 출력 size를 분리하여 원래 5/6픽셀 높이를 7픽셀로 늘렸다. 버튼 사이에는 10픽셀 간격이 있어 7픽셀 한글이 들어가며, 위쪽 LOAD의 끝 y=76은 BATTLE 시작 y=77 이전이다. 아래쪽은 LOAD(y147), SAVE(y157), 조작 패널(y167) 순서다. 배경 meleemenu-000의 같은 5개 기본 상태 버튼도 합성하여 초기 표시/배경 복구 후 영문이 남지 않도록 했다. 프레임 순서·핫스폿과 버튼 밖 배경 픽셀은 보존한다. 제목과 전투 시작 그림은 후속 번역 대상이다.

그림 메뉴 playmenu 0–37 및 64의 상단 제목 39개를 8픽셀 영역에 native 7픽셀 잉크로 치환한다. 배경은 원본처럼 투명하고 글자는 원래 회색이다. 아이콘 픽셀·ANI 순서·핫스폿은 보존한다. 31–34의 HUMAN/CYBORG는 후속 내부 라벨 번역으로 처리했고, 36의 장식 이름은 별도 미번역으로 남긴다. playmenu-heading-checks.json은 정적 검사이며 실기 가독성 확인은 대기다.

playmenu 31–34 내부 조작 라벨도 사람/사이보그로 번역했다. x=7..48, y=17..24의 42×8픽셀 띠만 짙은 파랑 바탕과 원래 빨강 글자 색으로 생성한다. 손·로봇·난이도 비행선은 y=25 이하를 포함해 이 영역 밖 원본 픽셀이 유지된다. 상단 제목을 포함한 두 영역 밖 RGBA 차이가 없는지 검사한다.

장비 그림 메뉴 16개를 module-labels.ko.json으로 생성한다. 제목 14개는 원본 11픽셀 영역에 7픽셀 한 줄로 배치하고 장비 그림(y11 이후)은 보존한다. 구매/판매도 원본 크기를 유지한다. DrawModuleStrings의 헤더 지우기 높이 11에 맞추며 ANI는 바꾸지 않는다. 긴 용어 3개는 회전 분사기/추적 장치/근접 방어로 원문 그림에 맞춘 UI 표기를 별도 기록하고 대화 용어는 유지한다. 반물질 추진기/고효율 연료계/융합 블래스터는 in_use 용어로 추가했다. 실기 선택 전환·가격 표시 검토는 남아 있다.

새 Fusion Blaster 용어를 연결하면서 버빅시즈 폐허 보고 원문도 대조했다. 기존 핵융합 포를 융합 블래스터로 맞추고 수치·문단·문장 말투는 유지했다.

함대 대전 이미지 5개에 제목/전투 2상태/세로 함선 선택·정보/불러오기·취소·스크롤 안내 8개를 생성한다. A/B/C와 화살표·격자·함선 그림·기존 번역 버튼은 유지한다. 제목만 native Galmuri7의 정수 2배(최근접) 14픽셀, 나머지는 7픽셀로 생성한다. 제목 뒤 별 배경은 글자 직사각형 안에서 검정으로 정리하고 밖은 보존한다. 입력 키 매핑은 바꾸지 않으며 실기 가독성은 확인 대기다.

playmenu 58의 증폭된 선구자 폭탄/탈출정, 59의 무제한, outfitmodules 55의 착륙정 공간 없음/탈출정을 원래 크기 안에서 번역한다. 폭탄 이름은 두 줄 native 7픽셀로 배치하고 그림은 유지한다. outfitmodules ANI와 나머지 55개 그림은 원본 바이트를 복사한다. 탈출정은 말하는 애완동물 대화의 기존 표기로 용어집에 등록하고 엔딩 0050의 탈출 포드도 통일했다.

엔딩 마지막 그림은 ending-card.ko.json으로 제목 영역만 생성한다. 마지막 슬라이드 스크립트의 ANI 경로 하나만 전용 애드온으로 연결하며 ANI 프레임 순서·핫스폿·다른 5개 PNG·음악/대기/전환 명령은 보존한다. 끝 제목은 Galmuri11 native raster 12의 이진 마스크를 정수 2배 확대한다.

컷신 PNG 초기 육안 검토는 261개 전체 경로를 포함한다. check_cutscene_image_review.py는 원본 패키지의 컷신 PNG 경로 집합·SHA-256·크기를 검토 기록과 대조하며, 육안 판단의 정확성이나 실제 재생을 자동으로 증명하지 않는다. LPF, 다른 자산군 및 실기 검토는 계속 남아 있다. 소개 연결 문구 2개는 번역했고 미연결 제작자 이미지의 상태를 별도 기록했다.

소개 title-001의 PRESENTS는 제공으로 생성하며 IFL/INTERSTELLAR FRUNGY LEAGUE는 회사 로고로 보존한다. title-004의 BY/AND는 제작/·로 바꾸되 이름 픽셀은 보존한다. title-004는 기본 패키지 ANI/TXT/RMP 참조가 없어 전용 번역 자산만 만들고 재생 경로를 새로 연결하지 않는다. title.ani의 두 프레임/위치와 게임 로고 title-002는 보존하며 소개 스크립트 ANI 경로 하나만 바꾼다.

조선소 라벨 21개는 기존 ships.ko.json의 0001 종족명과 (원본에 함종이 있을 때) 0003 함종명에 연결한다. 그림 너비 56, 핫스폿 (0,11)로 정렬하며 두 줄은 15픽셀, 한 줄은 11픽셀이다. 원본 선실/문/전력선 4개 프레임과 ANI의 프레임 순서·팔레트 필드는 보존한다. 배경은 원본 DrawRaceStrings의 RGB5(10,10,10)에 대응하는 회색 82로 생성한다.

조선소 한글은 작은 글자의 대비를 위해 원래 중간 회색 대신 밝은 회색 RGB(232,232,232)을 사용한다. 배경과 배치·조작 상태에는 영향을 주지 않는다.

SAFEX=16 변형 060/063에는 각각 빈 슬롯과 화물·장치·착륙선·자원·크레딧, 추가 실행/취소 안내가 있다. 일반 063에는 하단 A/B 안내가 없는 것을 별도로 확인했다. 두 변형은 기존 스크립트/ANI 연결을 변경하지 않고 ko/ui에 번역 자산만 준비한다. A/B와 숫자 1–10, 테두리 및 글자 영역 밖 픽셀은 보존한다. 설치된 실행 파일의 대체 경로 조회 여부는 미확인이다.


### LPF 검토 보충 (2026-09-26)

위의 LPF 미검토 상태는 이 보충 기록으로 갱신한다. 기본 패키지 victory1.lpf/victory2.lpf를 임시 FFmpeg 7.1로 디코딩해 기본 출력 89/131장을 모두 육안 확인했다. 우주선·창·폭발 그림과 숫자 카운트다운이며 번역할 문구는 발견하지 못했다. 원본을 보존한다. 해시·프레임별 출력 해시·헤더/페이지 레코드·도구 버전은 `lpf-image-review.json`에 기록한다.

헤더 101/133과 출력 수가 다른 이유도 확인했다. victory1은 빈 레코드 12개를 제외한 89개이며 마지막 루프 레코드가 기존 페이지에 있어 포함된다. victory2는 빈 레코드 1개와 별도 페이지의 마지막 루프 레코드 1개가 제외되어 131개다. FFmpeg n7.1 디먹서는 루프 플래그로 유효 레코드 수를 하나 줄이고 새 페이지를 찾을 때 그 한계를 검사하므로 두 배치에서 결과가 다르다. victory2의 제외된 레코드는 임시 복사본 헤더 byte 26만 0으로 바꿔 출력 index 131을 따로 확인했다. 첫 화면으로 돌아오는 그림이며 추가 문구는 없었다. 원본 파일은 수정하지 않았다.

재현: 별도 조사 환경에 `imageio-ffmpeg==0.6.0`을 설치하거나 동일 FFmpeg 빌드를 준비한다. 원본 LPF를 임시 폴더에 추출하고 `ffmpeg -i victory1.lpf -fps_mode passthrough frame-%04d.png`처럼 각각 별도 폴더로 출력한다. 이 도구는 패치의 설치 의존성이 아니다. `python tools/check_lpf_review.py --game "게임 경로"`는 원본·레코드 수와 기록의 연결만 검사하며 화면 내용이나 실제 게임 재생을 증명하지 않는다.

기본 패키지 ANI/TXT/RMP의 파일명 직접 참조는 없었다. 실행 파일의 확장자 자동 탐색·레거시 경로는 이 검사로 배제할 수 없다. 컷신 PNG와 LPF의 초기 육안 검토가 있어도 게임 전체 번역 완료를 뜻하지 않으며, 통신/함선의 다른 그림과 실기 검토는 남아 있다.


### 통신 이미지 검토 (2026-09-26)

`comm-image-review.json`은 기본 패키지 base/comm 아래 PNG 1,492개(25개 대화 자산 디렉터리) 전체의 원본 SHA-256·크기·검토 방법을 기록한다. 27개 큰 배경은 별도 배경 시트로 확인했고, 전체 파일은 순서가 고정된 15개 접촉 시트에서 검토했다. 드루지·스래대시·VUX·쇼픽스티 배경과 헤이스/스래대시/VUX 계기판 조각 36개는 최근접 확대했다. 스래대시 계기판 052는 추가 8배 확대했다.

읽을 수 있는 영문 문구를 발견하지 못했으므로 통신 그림은 보존한다. 계기 무늬나 외계 문자처럼 보이는 장식에 임의 번역을 붙이지 않는다. 이는 초기 육안 검토 결과이며 실제 합성 재생 검증이나 전체 게임 번역 완료가 아니다. 종족 폰트(base/fonts)와 대화 문자열은 기존 별도 검사 대상이다. 25개 통신 자산 디렉터리 수는 24개 종족 폰트 배정 수와 다른 분류다.

`python tools/check_comm_image_review.py --game "게임 경로"`는 전체 경로 집합·중복·원본 해시·크기·디렉터리별 수량을 대조한다. 자동 검사는 육안 판단의 정확성을 보장하지 않는다. 원본 게임 PNG나 접촉 시트는 저장소에 포함하지 않는다. 이번 조사에는 기존 Pillow만 사용했으며 신규 폰트/자산은 도입하지 않았다.

다른 미검토 PNG 자산군은 base/ships 3,903개, base/lander 331개, base/nav 294개, base/planets 177개, base/battle 117개다. UI와 컷신의 검토 결과를 이 자산군에 확대 적용하지 않는다. 통신 이미지 검토로 HUD CAPTAIN/FUEL/CREW 또는 playmenu-036 내부 장식 이름의 미완료 상태가 해소되지는 않는다.


### 항해·전투·행성·착륙 이미지 검토 (2026-09-26)

앞서 미검토로 남긴 base/battle 117개, base/lander 331개, base/nav 294개, base/planets 177개 PNG 총 919개를 10개 접촉 시트에서 초기 육안 검토했다. `world-image-review.json`에 전체 경로·해시·크기·검토 상태를 기록한다. base/ships 3,903개는 이 검토에 포함되지 않는다.

새 번역 대상은 두 이미지다. `base/lander/lander-032.png`(54×51)의 MIN/DAT 약어는 하단 잉크 높이가 5픽셀이라 기존 7픽셀 한글을 그대로 넣을 수 없다. 자원/생물 자료 의미와 실행 시 지우기 영역을 소스로 확인한 뒤 번역 영역을 정해야 한다. `base/nav/orbitenter-000.png`(242×75)의 ENTERING PLANETARY ORBIT...는 별도 그림 안내문이다. 원본 `graphics.orbitenter` → `base/nav/orbitenter.ani` → 해당 PNG 연결을 확인했으며 행성 그림·프레임 크기·핫스폿을 보존해 교체할 대상이다. 아직 두 이미지 모두 번역 적용하지 않았다.

`base/nav/orbitbackground-020.png`의 KG는 단위 기호로 보존한다. 두 번역 대상과 단위 이미지는 별도로 확대했다. 나머지 916개에서는 읽을 수 있는 언어 문구를 발견하지 못했다. 접촉 시트 결과는 합성 재생/동적 문자열/전체 게임 완료를 증명하지 않는다. `tools/check_world_image_review.py --game "게임 경로"`는 원본과 검토 기록의 전체 경로·해시·크기 연결 및 미번역 상태를 검사한다. 원본 그림·생성 접촉 시트는 Git에 배포하지 않으며 신규 외부 폰트/자산은 도입하지 않았다.

궤도 진입 안내 후속 적용: `행성 궤도 / 진입 중...` 두 줄을 native Galmuri7로 생성했다. 글자 영역은 (40,3,172,9), (94,14,60,9)이며, 배경은 각 행의 좌우 인접 픽셀 사이를 보간해 단색 사각형 자국을 줄인다. 한글 글리프는 반투명 없이 밝은 보라색으로 그린다. 두 영역 밖 RGBA, 242×75 크기, 원본 ANI 바이트·프레임 위치는 보존한다. graphics.orbitenter만 전용 ko/nav 리소스로 연결하며 실기 재생은 미확인이다. 위 919개 검토 중 미번역 이미지는 착륙정 MIN/DAT 한 개로 갱신한다.
