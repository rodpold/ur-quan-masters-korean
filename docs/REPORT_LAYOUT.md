# 탐사 보고의 한글 배치

원본 리소스 `font.lander`는 6픽셀 간격의 40열·12행 보고 화면에서 사용된다. 단순히 큰 한글 PNG를 추가하면 가로·세로가 겹친다. 실행 파일과 배경 프레임은 수정하지 않는다.

번역 원고는 `translations/reports.ko.json`에 정상적인 한글 문장과 원문 문단 단위로 보관한다. 패키지 생성 시 `report_layout.py`가 어절을 40칸 안에 배치하고 한글 뒤에 표시용 공백을 넣어 두 칸을 확보한다. 너무 긴 어절은 글자 경계에서 나누며 내용을 삭제하지 않는다. 각 페이지의 첫 행을 비우고 1·3·5·7·9행에 본문을 배치한다. 마지막 11행은 엔진의 `(다음)` 안내에 남긴다. 표시를 위해 생긴 공백·개행은 원고를 변경하지 않는다.

Galmuri9의 9픽셀 잉크는 10x12 PNG 상단에 놓인다. 원본 로더의 기준점은 높이-3=9다. 첫 본문 기준선 y=12에서 잉크는 y=3~11에 들어간다. 모든 생성 글리프의 알파는 0/255이며 원본 영문 PNG는 그대로 복사한다. 출처·라이선스·해시는 THIRD_PARTY.md와 translations/fonts.ko.json 참조.

`tools/check_report_layout.py`는 원작의 문자 분류·행 진행·MORE 삽입·페이지 재시작을 별도로 모사한다. 실제 패키지 글리프의 픽셀 좌표를 계산해 242x75 영역의 잘림과 중첩, 원고와의 본문 순서·누락을 검사한다. 9개 보고 46페이지가 통과했다. `docs/report-layout-checks.json`이 보고서별 결과다. 스페이서가 늘어 일부 긴 보고는 페이지 수가 많아진다.

검증 재현: `python tools/verify_build.py "게임 경로" --report-previews artifacts/report-previews`. 미리보기는 실제 게임 화면 캡처가 아니라 녹색 단색 정적 렌더다. PC 글자 색상 효과, 타이핑 속도, 키보드 페이지 전환, 창/전체화면 배치는 실기 검토가 남아 있다. 현재 Steam 실행 파일과 공개 포트가 완전히 같다는 주장도 하지 않는다. 시뮬레이터의 원작 출처와 별도 GPL 라이선스는 THIRD_PARTY.md 참조.
