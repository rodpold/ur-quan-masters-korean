# 대화 외 텍스트 목록

`python tools/inventory_text.py --game "게임 경로" --write-report`로 [text-inventory.json](text-inventory.json)을 생성한다. 설치된 기본 콘텐츠 패키지에서 대화와 탐사 보고를 제외한 38개 텍스트 파일을 검사한다. 원문 문구를 저장소에 복제하지 않고 항목 종류·순서·줄 수·해시를 기록한다.

| 종류 | 항목 수 | 후속 처리 |
|---|---:|---|
| 소개/최종 엔딩 TFI 자막 | 74 | 소개 32, 최종 엔딩 42. 타이밍과 명령 보존, 번역 및 폰트 연결 |
| 함선 회전 화면 TEXT 문구 | 12 | 좌표 보존, 번역 길이/배치 검토 |
| 크레딧 표시 블록 | 55 | 인명·URL·역할·감사 문구를 별도 보존/번역 분류 |
| 연출 제어 명령 | 1599 | 원문 보존. 번역 대상으로 세지 않음 |
| 비어 있는 주석 블록 | 68 | 원문 보존 |
| UI/설정 문자열 블록 | 710 | 기존 번역과 연결해 누락 확인, 빈 블록은 별도 집계 |
| 함선 관련 첫 다섯 이름 슬롯 | 125 | 표시 소비 코드 확인 후 종족명/함급명 번역 |
| 나머지 함장 이름 후보 슬롯 | 403 | 이름·세이브 영향 확인 후 용어집 연결 |
| 이름 입력 문자표 | 3 | 입력 기능으로 따로 검토; 일반 문장으로 번역하지 않음 |
| 이미지 글자 참고 파일 | 1 | pc_credits.txt는 게임에서 직접 쓰지 않는 참고 자료임을 원문에서 확인 |

`#(...)`는 대화에서는 식별자로 쓰이지만 슬라이드에서는 설명 주석으로 반복된다. 따라서 사전으로 변환하면 항목을 잃을 수 있다. 이 도구는 순서 ID를 사용하며 그 ID는 원본 파일 해시와 함께만 유효하다. TEXT의 좌표와 크레딧의 글꼴 크기·열 정렬은 문구와 분리한다. 모르는 명령이나 제어 명령 뒤 예상치 못한 본문은 오류로 처리한다.

이 목록은 번역 완료표가 아니다. 함장 이름 분류는 위치에 따른 후보 분류이며 원본 소비 코드를 확인해야 한다. 이미지·영상 내 글자, 별도 애드온 판본은 포함하지 않는다. 승리 애니메이션 victory1/victory2와 ending 호출 파일에 TFI/TEXT가 없다는 사실만 확인했으며, 그 그림에 영문이 없다는 뜻은 아니다.

검증: 중복 표제 보존, 여러 줄 자막, 좌표 분리, 크레딧의 탭·빈 줄 보존, 미확인 명령 거부 회귀 테스트 5개. 기존 검사를 포함한 35개 테스트 통과. 게임 파일·설치 패키지는 이번 목록 도구 변경으로 수정하지 않는다.

다음 작업: 소개 32개 자막 번역 → 슬라이드용 글리프/연출 명령 보존 검사 및 패키지 연결 → 엔딩/회전 화면 → UI·이름·크레딧 분류와 번역. 전체 대화의 언어·실기 검토도 별도로 남아 있다.

함선 소개의 위치 지정 문구 12개는 [재생 경로 조사](SHIP_SPIN_SCOPE.md) 결과 현재 설치 패키지에서 리소스 연결이 발견되지 않았다. 활성 텍스트 번역률의 분모로 단정하지 않고 원본 목록에 남긴다. 다른 함선 정보 텍스트는 여전히 조사·번역 대상이다.
