## 완료 기준

1. 원본에서 발견한 모든 사용자 표시 텍스트가 번역 또는 근거 있는 보존 처리됨.
2. 고유명사·말투·문맥·화자·숫자·변수·음성 구간 검토 완료.
3. 모든 번역 글리프와 종족별 줄바꿈·자막 영역·선택지·UI 실기 확인.
4. 원본/세이브/오디오 보존, 설치·업데이트·제거 검증.
5. 라이선스·출처·번역 진척·남은 문제 문서와 GitHub 일치.

## 검증과 다음 순서

`python tools/check_localization.py --game "게임 경로" --write-report`로 번역 누락, 잠금 용어, 페르소나 연결, 대사 ID/줄 수/숫자 검사를 갱신한다. 말투 품질은 자동 검사만으로 보장되지 않으므로 별도 번역 검토와 실기 확인이 필요하다.

다음은 각 종족별 전체 대화 → 탐사/함선/소개/엔딩 및 UI 잔여 항목 순으로 진행한다. 번역 중 원작의 고유 표현과 새 이름은 용어집에 추가하고 기존 잠금 표기를 바꾸지 않는다.
