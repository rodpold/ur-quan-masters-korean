# 전체 한국어 번역 목표와 진행률

목표: 게임 전체 텍스트를 번역하고 적용·검증한다. 종족별 흑백 폰트, 기존 고유명사 유지, 종족/화자/진행 상태별 페르소나를 준수한다. 음성·대화 분기·변수·좌표·세이브를 보존한다.

## 현재 상태

- 종족별 폰트: 24개 독립 파일 / 27개 대화 연결 설치. 실기 검증 대기.
- 대화: 394 / 3451 레코드 초안 번역 (11.42%). 이는 게임 전체 완료율이 아니다.
- 탐사선 86/86, 헤이스 초반 대화 99/99 레코드 초안. 우르콴 경고 방송 1레코드 시험 번역. 대화 품질·실기 검토는 별도 진행.
- 우주기지: 208/300 레코드 초안. 귀환 인사·광물 납품·기지 기능·전략 조언·선택지 포함. 긴 역사/장비 보고 92개는 남아 있음.
- 음성판: 별도 원문을 사용하는 6종을 감지하고 변경된 대사는 명시적 번역 검토 후 적용. [처리 기준](VOICE_EDITIONS.md).
- 페르소나: 24개 기본 규칙과 복수 화자/상태별 예외. [규칙](../translations/PERSONAS.md).
- 기존 용어: 38개 표기 잠금. 새 용어는 등록 후 사용.
- 대화 외: 공통 UI/설정 일부 기존 구현. 탐사 보고·함선 정보·소개·엔딩·크레딧 등 전체 목록은 localization-progress.json으로 추적, 내용별 번역/보존 분류 필요.

## 완료 기준

1. 원본에서 발견한 모든 사용자 표시 텍스트가 번역 또는 근거 있는 보존 처리됨.
2. 고유명사·말투·문맥·화자·숫자·변수·음성 구간 검토 완료.
3. 모든 번역 글리프와 종족별 줄바꿈·자막 영역·선택지·UI 실기 확인.
4. 원본/세이브/오디오 보존, 설치·업데이트·제거 검증.
5. 라이선스·출처·번역 진척·남은 문제 문서와 GitHub 일치.

## 검증과 다음 순서

`python tools/check_localization.py --game "게임 경로" --write-report`로 번역 누락, 잠금 용어, 페르소나 연결, 대사 ID/줄 수/숫자 검사를 갱신한다. 말투 품질은 자동 검사만으로 보장되지 않으므로 별도 번역 검토와 실기 확인이 필요하다.

다음은 기지 역사·장비 보고 잔여 92개 → 스파시 첫 조우 → 각 종족별 전체 대화 → 탐사/함선/소개/엔딩 및 UI 잔여 항목 순으로 진행한다. 번역 중 원작의 고유 표현과 새 이름은 용어집에 추가하고 기존 잠금 표기를 바꾸지 않는다.
