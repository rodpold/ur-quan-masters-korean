## 완료 기준

1. 원본에서 발견한 모든 사용자 표시 텍스트가 번역 또는 근거 있는 보존 처리됨.
2. 고유명사·말투·문맥·화자·숫자·변수·음성 구간 검토 완료.
3. 모든 번역 글리프와 종족별 줄바꿈·자막 영역·선택지·UI 실기 확인.
4. 원본/세이브/오디오 보존, 설치·업데이트·제거 검증.
5. 라이선스·출처·번역 진척·남은 문제 문서와 GitHub 일치.

## 검증과 다음 순서

`python tools/check_localization.py --game "게임 경로" --write-report`로 번역 누락, 잠금 용어, 페르소나 연결, 대사 ID/줄 수/숫자 검사를 갱신한다. 말투 품질은 자동 검사만으로 보장되지 않으므로 별도 번역 검토와 실기 확인이 필요하다.

대화 레코드의 첫 초안은 모두 채웠다. 다음은 함선/소개/엔딩/크레딧 및 UI 잔여 항목을 분류·번역하고, 전체 대화의 의미·말투·레이아웃·실기를 검토한다. 번역 중 원작의 고유 표현과 새 이름은 용어집에 추가하고 기존 잠금 표기를 바꾸지 않는다.

대화 외 텍스트는 [구조별 목록](TEXT_INVENTORY.md)에서 추적한다. 소개/최종 엔딩 자막 74개, 위치 지정 문구 12개, 크레딧 블록 55개를 연출 명령과 분리했다. 아직 번역 완료가 아니며 이미지 내 텍스트·애드온 판본은 별도 조사 대상이다.

소개: 기본 PC 슬라이드 자막 32개 초안 및 애드온 연결. 원본 연출 명령·음악 동기화 보존 검사와 글리프 폭 검사 추가. 실제 재생·대체 영상 판본 검토 대기. 엔딩·크레딧·회전 화면·이름 및 UI 잔여 번역도 미완료다.

최종 엔딩 슬라이드 42개 번역 초안을 추가했다. 소개 32개와 합쳐 TFI 자막 74개가 패키지에 연결됐다. 문장·화자 검토와 실제 엔딩 재생 검증은 계속 필요하며 게임 전체 완료로 계산하지 않는다.

함선 소개 프로토타입의 TEXT 12개는 설치 리소스 연결이 없음을 확인했다. docs/SHIP_SPIN_SCOPE.md와 해시 기록을 참조. 잠든 기능을 추가 활성화하지 않으며 함선명·함장명·활성 UI 번역은 계속 진행한다.

공통 게임 문자열은 tools/check_ui.py와 docs/ui-progress.json에서 원문 해시·순서 ID별로 추적한다. 공백/단위/사용자 변경 가능한 기본 이름 보존과 번역 대기를 구분한다. UI 초안 확장 후 실제 메뉴·네트워크 안내·행성 수치 화면은 실기 검토 대상이다.

성도·천체 이름 UI 초안을 추가했다. docs/celestial-name-review.json에 용어집 대응과 Mercury 예외를 기록했다. 성도 한글 검색/입력과 긴 이름 화면 배치는 실기 검토 대상이다.

장치 목록 28개 레코드 초안을 적용했다. translations/device-labels.ko.json에 줄 분리·좁은 표시 영역 조건을 기록하고 실제 PNG 너비/잉크 높이와 흑백 알파를 검사한다. 실기 선택·스크롤 검토는 남아 있다.

원소 94종과 행성 수성의 문맥별 번역을 추가했다. ui-overrides.ko.json의 원문 해시·순서 ID 검사로 수은/수성 혼동을 방지한다. 광물 수집 텍스트의 글리프/7픽셀 높이를 검사했으며 이동·가장자리 실기 검토는 남아 있다.

화합물·특수 자원 39종(동일 Water 행성 유형 포함 UI 40개 레코드)을 추가 번역했다. materials.ko.json에서 분야별 용어를 관리하고 material-layout-checks.json에서 수집 화면의 글리프·높이를 추적한다. 행성 유형 전체는 아직 번역 대기다.

공통 gamestrings.txt의 번역 대기 레코드를 모두 초안으로 채웠다. 빈 레코드 5개와 단위/사용자 변경 가능한 기본 이름 8개는 명시적으로 보존한다. 이 결과는 게임 전체 완료가 아니며 설정·함선 정보·팀 파일·크레딧·이미지/영상 텍스트·실기/의미 검토가 남아 있다.

설정 121개 레코드의 초안 범위와 숫자/목록 보존 검사를 setup-progress.json에 별도 기록했다. 일부 설명의 원문 누락·추가 권장 문구를 수정했다. 기술명과 실제 제작진 이름은 원어를 유지하며 실기·언어 검토는 계속 필요하다.

25종 함선 문자열의 첫 5개 레코드(종족명·함종명·약칭) 125개 초안을 추가했다. ships.ko.json과 ship-label-checks.json에서 용어/폭/원본 순서를 확인한다. 함장명 403개는 미번역이며 별도 진행해야 한다. 실제 함선 선택·함대 정보·전투 HUD·저장 불러오기는 실기 검토 대기다.

함장명 403개를 검토용으로 분류했다. 371개 한국어 초안과 코드형 이름 32개 원어 보존을 구분하여 패키지에 연결했다. 함장명 입력 대기는 0이지만 발음·의미 검토, 실기 표시와 저장 호환성 검증은 완료되지 않았다. 숫자·별표·레코드 순서와 TinyFont 60픽셀 이내 표시 폭을 검사한다.

크레딧 비어 있지 않은 55개 블록 중 33개 블록에 역할/배역/감사 문구 번역을 넣었다. 나머지 22개는 제작자 이름·URL·라이브러리 이름·여백을 원형 보존한다. 명령/탭/이름 보존과 세 폰트 높이/폭/버퍼 검사를 추가했다. 실제 스크롤·가독성·최종 언어 검토는 남아 있다.
