  타 파일 보존, 설치/제거, 업그레이드, 디스크 오류 시 롤백, 음량 설정 보존.

## 수동 검사 순서

1. 게임 종료 후 install 실행. launch --test-config artifacts/test-profile 사용.
2. 시작 화면에서 설정 진입. 화면, 소리, PC/3DO, 조작, 고급 페이지를 확인.
3. 기존 음량을 바꾸지 않고 효과음/음악 재생 확인.
4. 새 게임에서 태양·함장·연료·승무원·날짜·오른쪽 메뉴 확인.
5. 성도 → 돌아오기, 함선 정보 → 화물/장치/함대 화면 확인.
6. 게임 → 저장 → 빈 슬롯 저장. 돌아와 불러오기 후 위치·날짜·자원 확인.
7. 종료 후 uninstall. 애드온 폴더 제거와 원본 해시 보존 확인.
8. install 재실행. Steam 실행 옵션으로도 같은 결과인지 확인.

저장 테스트는 반드시 독립 테스트 프로필에서 수행합니다.

## 9픽셀 시험 옵션

`--ui-font larger`는 starcon 한글을 10×9픽셀 잉크 영역으로 만듭니다.
기본 7픽셀 옵션을 유지하며 설치 시 선택할 수 있습니다.
단위 테스트 8개와 larger 패키지 검사를 통과했습니다.
9픽셀 패치를 설치하고 재실행한 소리 설정 화면에서 확인했습니다.
- 음·끔의 받침은 커졌지만, 상단 UQM 설정/소리 설정 두 제목이 겹칩니다.
- 일부 획이 끊겨 보이며 왼쪽 항목의 가장자리 잘림도 남아 있습니다.
- 소리 항목 행끼리의 겹침은 보이지 않고 세 음량은 모두 100입니다.
- larger는 시험 옵션으로 유지합니다. 9픽셀 글리프와 제목 배치 보완 전에는 기본값으로 채택하지 않습니다.

### 9픽셀 획 손실 수정

최초 larger는 Galmuri11을 비권장 크기 10px로 래스터화하여 켬의 ㅋ·ㅕ 획을 손실했습니다.
Galmuri9를 권장 크기 10px로 사용하도록 변경했습니다. 글리프 크기(10×9)와 배치는 같습니다.
설치 전 패키지 검사 및 켬의 픽셀 회귀 검사를 수행합니다. 실기 재확인은 재시작 후 필요합니다.
제목 겹침과 왼쪽 가장자리 문제는 이번 글꼴 교체로 해결되지 않습니다.

### 9픽셀 설정 제목 겹침 수정

Galmuri9 적용 후 소리 설정에서 켬·끔의 획과 상단 두 제목 겹침을 확인했습니다.
공개 widgets.c에서 제목 기준선 간격이 8픽셀로 고정됨을 확인했습니다.
larger 빌드는 공통 제목을 공백으로 두고, 각 페이지 부제목 한 줄만 표시합니다.
설정 첫 페이지의 빈 부제목은 UQM 설정으로 채워 제목을 유지합니다.
헤더·항목 개수는 보존하며 실행 파일은 변경하지 않습니다. 실제 수정 화면은 재실행 후 확인해야 합니다.

## 사용자 대화 화면 확인 및 다음 시험

사용자가 9픽셀 오른쪽 목록의 겹침과 로그·헤이스 자막·플레이어 선택지 화면을 제공했습니다.
오른쪽 목록에는 7픽셀을 사용하고, 대화는 전용 폰트로 분리하는 방향으로 전환합니다.
테스트 프로필의 uqmsave.00 존재 및 별도 바이트 동일 백업을 확인했습니다.
대화 번역은 아직 미적용이며 [대화 시험 계획](DIALOGUE_TEST_PLAN.md)에 리소스와 검증 기준을 기록했습니다.

## 첫 교신 부분 번역 구현

우르콴 SEND_MESSAGE, 헤이스 ARE_YOU_SUPPLY_SHIP 및 첫 선택지 3개(분할 포함 총 6레코드)를 구현했습니다.
318개 한글 음절을 생성하며 player/urquan 9픽셀, compact starcon/tiny 7픽셀로 분리했습니다.
comm.commander.font를 한글 player 폰트에 연결하고 음성 애드온의 원래 참조 경로를 보존합니다.
미번역 대사는 그대로 두고 헤더와 원본 발화 줄 수를 검사합니다. 후속 응답은 아직 번역 범위 밖입니다.
게임 실행 중이므로 설치 및 실제 대화 화면 검증은 아직 진행하지 않았습니다.


## 실제 빌드 설치 수명주기 검증 (2026-09-26)

`tools/verify_install_lifecycle.py --game "게임 경로" --report docs/install-lifecycle-checks.json`은 검증된 원본 패키지·실행 파일·설치된 음성/3DO 음악 패키지를 임시 폴더로 복사해 실제 번역 빌드로 검사한다. 원래 게임 폴더에는 설치/제거를 수행하지 않으며 게임도 실행하지 않는다. 저장소의 기존 3451개 대화 초안 등 전체 빌드를 사용한다.

- 신규 compact 설치 후 패키지·manifest 두 파일만 추가되는지 확인한다.
- 동일 compact 재설치가 같은 상태를 반환하고 두 파일의 수정 시각을 바꾸지 않는지 확인한다.
- larger 시험 옵션으로 서로 다른 실제 패키지를 만들어 업데이트한다. 실제 게임의 compact 설정은 유지한다.
- 제거 및 반복 제거 후 원본 파일 목록·해시가 초기 상태와 같은지 확인한다.
- 임시 설정·세이브 표본과 관련 없는 애드온, 원본 EXE·콘텐츠·음성·음악 패키지를 모든 단계에서 해시 비교한다. 실제 사용자 세이브 파일을 읽거나 변경하지 않는다.

제거 중 manifest 삭제가 공유 위반으로 실패하거나 마지막 폴더 삭제가 실패하면 이미 삭제된 소유 파일을 복구하도록 보완했다. 두 오류를 주입한 회귀 테스트는 기존 설치 상태를 되찾는지 검사하며 전체 87개 테스트가 통과했다. 쓰기까지 계속 거부되는 경우나 프로세스 강제 종료/정전의 복구를 보장하지 않는다. 다른 버전 간 마이그레이션·배포 실행 파일·실제 게임 내 번역/세이브 로딩 검증은 별도 미완료 범위다.
