# 0.1 검증 기록

2026-09-25 / Windows / Steam UQM 0.8.0

## 자동 검사 통과

- 단위 테스트 8개: 중복 문자열, 빈 설정 항목/개수, 수정된 파일 제거 거부,
  타 파일 보존, 설치/제거, 업그레이드, 디스크 오류 시 롤백, 음량 설정 보존.
- 로컬 패키지 검사: 같은 입력의 바이트 단위 재현성, ZIP 무결성,
  모든 RMP/ANI 경로, 문자열 헤더와 순서, 원본 영문 글꼴 보존,
  한글 PNG 알파 채널, 저장 화면 이미지 크기.
- 번역에 쓰인 한글의 빈 글리프·누락 글리프 검사(두 폰트),
  설정 설명문 폭 300픽셀 이하, 주요 오른쪽 메뉴 폭 54픽셀 이하 검사.
- 공통 문자열 115곳, 설정 리소스 121개, 한글 271자 × 4개 폰트.
- 설정 설명문의 최대 폭: 191 게임 픽셀(기본 화면 폭 320).

| 항목 | 상태 |
|---|---|
| 시작 메뉴 5개 한글 표시 | 확인 |
| 초반 HUD 및 목록 메뉴 | 이전 시제품의 사용자 화면으로 확인 |
| 확장 설정 화면 / 하위 페이지 | 검증 중 |
| 저장/불러오기 왕복 | 검증 대기 |

| 원본 데이터·개인 세이브 해시 보존 | 기록한 실제 파일 5개 해시 일치 |
| 설치 → 제거 → 재설치 | 실제 원본 데이터 복사본의 독립 폴더에서 통과. 실제 게임 경로는 설치·업데이트 확인 |
| 오디오 | 음량 100, SDL 오디오 초기화 확인. 청취 확인은 별도 필요 |

자동 키 입력이 게임에서 동작하지 않아 화면 전환은 사용자 조작의 도움을 받아 검증 중입니다.
위 상태는 자동 검증 성공과 화면 검증 성공을 구분합니다.

## 수동 검사 순서

1. 게임 종료 후 install 실행. launch --test-config artifacts/test-profile 사용.
2. 시작 화면에서 설정 진입. 화면, 소리, PC/3DO, 조작, 고급 페이지를 확인.
3. 기존 음량을 바꾸지 않고 효과음/음악 재생 확인.
4. 새 게임에서 태양·함장·연료·승무원·날짜·오른쪽 메뉴 확인.
5. 성도 → 돌아오기, 함선 정보 → 화물/장치/함대 화면 확인.
6. 게임 → 저장 → 빈 슬롯 저장. 돌아와 불러오기 후 위치·날짜·자원 확인.
7. 종료 후 uninstall. 애드온 폴더 제거와 원본 해시 보존 확인.
8. install 재실행. Steam 실행 옵션으로도 같은 결과인지 확인.

저장 테스트는 반드시 독립 테스트 프로필에서 수행합니다.
