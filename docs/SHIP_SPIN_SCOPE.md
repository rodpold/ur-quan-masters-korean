# 함선 소개 스크립트의 적용 범위

현재 설치된 기본·3DO 음악·음성 패키지의 모든 `.rmp`를 확인했지만 `slides.spins.*` 연결은 없었다. 기본 패키지에는 ship00/04/10의 스크립트·ANI·그림이 있고 TEXT 문구가 각 4개씩 있다. 이 12개는 활성 화면에서 읽히는 문자열로 확인되지 않았다. 번역을 이유로 새 리소스 연결을 만들어 잠들어 있는 기능을 활성화하지 않는다. 다른 함선 정보·이름·대결 화면의 번역 범위는 그대로 남는다.

공개 소스의 `fmv.c:DoShipSpin`은 `slides.spins.%02u`를 재생하며 `WANT_SHIP_SPINS`로 컴파일 조건이 나뉜다. `shipyard.c`에서는 특수 버튼으로 호출한다. 설치 EXE의 빌드 플래그나 같은 동작은 아직 확인하지 못했다. 추가 영상 팩을 설치한다면 해당 팩의 리소스와 영상 내 텍스트를 다시 조사해야 한다.

원문 경로·SHA-256, 공개 소스의 URL·해시는 [기계 판독 조사 결과](shipspin-resource-audit.json)에 기록했다. 원본 C 파일과 게임 그림은 저장소에 포함하지 않는다.

같은 조사에서 `intro.c`의 FONT 명령은 글꼴 로딩과 선택을 동시에 수행함을 확인했다. 슬라이드 정적 검사기에 이 동작을 반영했다. TFI는 512바이트 버퍼와 최대 15줄, TEXT는 최대 255바이트 한 줄을 사용한다. 한국어 UTF-8 바이트 수가 문자 수와 다르므로 소개·엔딩 검사에 TFI 한도를 추가했다. 실제 읽기 시간·세로 배치·게임 실행 검토는 별도다.
