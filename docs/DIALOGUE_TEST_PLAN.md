# 대화 한글화 시험 계획

2026-09-25. 사용자 제공 실제 화면과 설치 데이터 및 공개 소스 조사 결과.
설정 화면 시험에서 대화 시험으로 진행한다. 게임 실행 파일은 변경하지 않는다.

## 영역별 제약

| 영역 | 리소스/동작 | 첫 시험 방침 |
|---|---|---|
| 오른쪽 목록 | starcon, 고정 8픽셀 줄 간격 | 9픽셀 시험에서 겹침 확인. 7픽셀로 복구 |
| 초록색 대화 로그 | TinyFont, DELTA_Y_SUMMARY=8 | 7픽셀 유지, 페이지 넘김과 마지막 문장 확인 |
| 플레이어 선택지 | font.player, 폰트 leading 사용 | Galmuri9 9픽셀 후보, 여러 줄 및 긴 선택지 스크롤 검증 |
| 상대 자막 | comm.<종족>.font, 종족별 폭/기준선 | 종족별 독립 글꼴 매핑. 먼저 9픽셀로 동작 확인 |

설정과 오른쪽 목록이 공통 starcon 폰트를 공유한다. 따라서 starcon을 전역으로 키우지 않는다.
우선 compact를 기반으로 대화 전용 폰트를 분리한다. 설정의 큰 글꼴 유지가 필요하다면
설정 문자열에만 별도 글리프 코드 영역을 쓰는 리소스 방식 등을 별도 검토해야 한다.
9픽셀 글꼴은 Galmuri9를 권장 10px로 래스터화한다. 다른 크기용 픽셀 글꼴을 축소하지 않는다.

## 첫 시험 대상

1. 우르콴 지구 경고 방송: base/comm/urquan/urquan.txt의 SEND_MESSAGE.
   초록색 로그와 원래 종족 자막이 같은 번역을 표시하는지 확인한다.
2. 헤이스 사령관 첫 인사: base/comm/commander/commander.txt의 ARE_YOU_SUPPLY_SHIP.
   화면 우측 상단 자막 폭은 공개 소스상 143 게임 픽셀이다.
3. 첫 선택지: no_but_well_help0/1, yes_this_is_supply_ship, what_slave_planet.
   첫 항목은 두 문자열 사이에 사용자 함선 이름이 삽입되므로 분할과 삽입 위치를 보존한다.
4. 각 선택 직후 응답까지 검증해 선택지 ID와 분기가 유지되는지 확인한다.

예시 문안(아직 패치에 적용하지 않음):
- 인사: 미확인 우주선에 알린다! / 나는 지구 우주기지 사령관 헤이스다.
- 선택: 아니요. 여기는 [함선명]호입니다. 도움이 필요하면 돕겠습니다.
- 선택: 어… 네, 보급선입니다. 무엇이 필요하죠?
- 선택: 노예 행성? 지배 계층의 보급선? 무슨 일이 있었던 겁니까?

## 리소스 처리

- 대사는 UTF-8 텍스트로 관리하고, 글꼴은 유니코드 음절별 PNG로 생성한다.
  현재 확인 범위에서는 초성·중성·종성을 엔진에서 조합할 필요가 없다.
- UI 번역과 별개로 translations/dialogue/<종족>.ko.json에 대사 ID별 번역을 둔다.
- 원문 헤더, 순서, ID, 음성 파일명, 문장 조각 및 동적 이름 삽입을 보존한다.
- 음성 연결 및 자막 구간 경계를 조사한 뒤 원래 발화 구간 단위로 번역한다.
  화면 폭에 맞추려는 임의의 원본 줄 합치기는 피하고, 자동 줄바꿈과 구간 분리를 구분한다.
- 로그는 실제 재생한 자막을 가져온다. 별도의 로그 번역본을 중복 관리하지 않는다.
- comm.commander.font는 원본 player.fon을 직접 가리킨다.
  font.player만 바꿔서는 사령관 자막에 한글이 보장되지 않으므로 별도 RMP 재정의가 필요하다.
- 모든 종족에 같은 글꼴을 확정하지 않는다. 첫 시험 통과 후 종족별 크기·폭·분위기와
  라이선스를 기록하는 폰트 매핑표로 확장한다.

## 검증 기준

- 번역에 필요한 모든 글리프 존재, 음성 파일명과 대사 ID/순서 불변.
- 긴 한국어 어절, 문장부호, 긴 함선 이름, 여러 줄 선택지의 줄바꿈/스크롤 확인.
- 상대 자막이 얼굴/장식 영역을 과도하게 가리지 않고 마지막 줄이 잘리지 않을 것.
- 로그 다음 페이지와 마지막 문장, 선택지 강조 및 키보드 선택 동작 확인.
- 원래 영어 음성 재생과 자막 구간 대응 확인. 음량 변경 없음.
- 같은 저장본에서 반복 로드하며, 시험 진행 후 저장은 다른 슬롯에 할 것.

## 저장본

사용자가 test-profile/save/uqmsave.00을 생성한 것을 확인하고,
artifacts/save-backups/<내용 해시 접두사>/uqmsave.00에 동일 바이트 백업했다.
파일 존재와 백업 해시는 확인했지만 실제 로드 가능한 시점/상태는 아직 검증하지 않았다.
저장본과 백업은 Git 제외 대상이며 공개 저장소에 추가하지 않는다.

## 2026-09-26 검증 업데이트

초기 계획의 예시·후보 표기는 현재 적용 상태가 아니다. 현재 24종 폰트 배정은 translations/FONTS.md 및 fonts.ko.json을 따른다. 헤이스 첫 선택지와 짧은 로그, 우르콴 경고 일부 자막은 실제 화면에서 확인했다. 긴 로그 페이지 전환은 사용자가 확인했다. 이후 TinyFont 여백 보정은 상단 지명·연료 잘림 해결이 사용자 확인됐으며, 같은 폰트를 공유하는 로그도 1픽셀 내려간다. docs/tiny-context-bounds-review.json에서 8픽셀 로그 간격 및 HUD 수직 범위를 설치된 모든 한글 TinyFont 글리프로 확인했다. 이 정적 검사는 보정 후 긴 로그의 실제 페이지 전환을 대신하지 않는다.

## 이후 플레이 검수 방식 (사용자 요청, 2026-09-26)

사용자가 게임을 진행하며 피드백을 제공하고, 그 피드백에 맞춰 번역·폰트·레이아웃을 수정한다. 자동 검증을 위해 클라이언트를 반복 실행하지 않는다. 다음 실행·재시작은 사용자의 요청에 맞춘다. 사용자 확인: 우측 메뉴의 우주 지도는 잘리지 않고 표시된다. 이 확인을 다른 화면이나 전체 종족 검증으로 확대하지 않는다.
